# Ansible — Automatiser la gestion de serveurs

**Auteur : Youghourta Merabtène**

Formation de deux jours (12 h) à l'automatisation de la gestion de serveurs avec
Ansible : architecture, installation, commandes *ad hoc*, playbooks, rôles,
variables et supervision. Chaque séquence est close par un laboratoire
reproductible sur un environnement isolé.
